# 叩仙门：青岚纪

![叩仙门：青岚纪 · 晨光云海与烟火人间](public/assets/qinglan-prologue.webp)

> 山河未老，故人先秋。此去青岚，愿你历尽千劫，仍记得为何出发。

**[立即游玩 · 官方网站](https://xiuxian.011203.xyz/)**

一世修行，叩问仙门。

## 仙途一览

- **法宝与功法**：在正道与魔功之间取舍，搭配法宝与功法，通过炼器和仙器觉醒逐步成型。
- **秘境历练**：地域妖物与妖王招式各有差异，随着历练深入迎接更险的挑战，最终叩入仙门，为此世落幕。
- **修行与人间**：五行命盘、灵根轮回、寿元、仙途履历与灵威，百年城景变迁、三代炉火旧事、凡人道侣与故人来信、AI 闲谈与带配图的茶馆听书、拜入宗门，研习与委托直接消耗年岁结算。
- **丹香入道**：战前备药、药铺轮换、每世不同的丹方与炼丹，在人间游历中偶遇丹缘。
- **随时入境**：支持电脑、手机与自动历练，本地存档可导出、导入。

电脑使用 WASD / 方向键，手机拖动走位，横竖屏跟随设备与系统设置。完整玩法见游戏内「修行指南」。

## 本地运行

需要 Node.js 22.18+。

```bash
npm ci
npm run dev -- --port 5173 --strictPort
```
