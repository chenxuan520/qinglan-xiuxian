# 青岚仙途

一款青绿色仙侠风的 Web 幸存者游戏。只需操控走位，法宝自动攻击；斩妖、拾取灵气、搭配功法，从炼气一路修至渡劫。

## 本地运行

需要 Node.js 22.18+ 和 npm。

```bash
npm ci
npm run dev
```

打开终端显示的地址，默认是 `http://localhost:5173`。手机与电脑在同一局域网时，可使用终端显示的 Network 地址访问。

```bash
npm test           # 战斗、成长、存档与立绘映射测试
npm run build      # TypeScript 检查与生产构建
npm run preview    # 预览 dist 中的生产版本
npm run balance    # 固定种子的难度与六境连续战斗模拟
npm run format:check
```

## 玩法

- 电脑：WASD / 方向键移动，Esc / P 暂停，升级时按 1 / 2 / 3 选择。
- 手机：按住战斗画面拖动虚拟摇杆，松开停止移动。
- 「AI 代打」可在主页、战斗、暂停或升级界面开关：自动走位、避敌、拾取与选择法宝功法，优先配套和仙器进化。方向键 / WASD 或触屏移动会切回手动；后台、暂停和结算时不继续操作。无需配置密钥。
- 攻击自动进行。靠近灵气结晶自动拾取，升级时获得三选一，每局可重悟 3 次。
- 每局最多 6 件法宝与 4 种功法。法宝六重、配套功法三重后，可选择仙器进化。
- 每分钟有精英妖物；倒计时结束后妖王出现，击败妖王才算通关。
- 右上角「?」为修行指南，包含操作、道具效果、全部进化配方和存档说明；战斗中打开会自动暂停。

## 内容

36 件法宝，正道与魔道各 18 件。新增古琴声浪、笔阵连印、驻地灵塔、三才阵旗、药鼎回复、追踪笛音、周身念珠、十字星线、玄伞消弹、贯穿长枪、残血斩镰、追魂连钉、棺落冥土、牵引长鞭、穿透骨灵、汲血池、蛊巢毒爆、裂镜分片、巨斧震退、错时落星。每件均有攻击特色与仙器觉醒。

16 种辅助功法，正道与魔道各 8 种。正道提供御剑、冷却、范围、护体、长生、暴击、聚灵和紫府成长；魔道提供增伤承伤交换、残血加速、命中减速、受伤骨刺、斩妖回复、暴击强化、击杀拘魂和逆命成长。完整数值和配方见游戏内图鉴。

每次出发前可选择正道、魔道或兼修。纯修只能选择本流派本命法宝，新领悟也只出现本流派法宝和功法；兼修自由混搭。正道额外气血 +12、每秒回复 +0.2，魔道额外法宝伤害 +12%，兼修没有额外路线加成。携带上限仍为 6 件法宝与 4 种功法。

觉醒条件为法宝六重、配套功法三重，再升级时优先出现「仙器觉醒」。每件法宝均有正、魔功法配方，兼修满足其中一条即可；纯修按当前路线配套。图鉴可按流派筛选，36 件法宝和 16 种功法的图标全部使用同一风格的生成图片。

28 种普通妖物和 6 位独立造型的妖王。新关卡保留之前妖物，后四境每境累计增加 4 种高阶妖物，完整妖物池依次为 12、12、16、20、24、28 种；局内随时间逐步加入。除了追击、远程、冲刺、重甲、自爆、召唤和毒域，新增扇形散射、环射弹幕及亮盾减伤。原有精英强度保留，后期有机会出现高阶精英。

| 秘境     | 妖王出现时间 | 妖王     |
| -------- | ------------ | -------- |
| 青岚竹海 | 5 分钟       | 苍木妖王 |
| 落霞古墟 | 6 分钟       | 赤炎狐王 |
| 玄冰幽谷 | 7 分钟       | 霜魄狼王 |
| 万毒深泽 | 8 分钟       | 玄甲毒君 |
| 九幽冥府 | 9 分钟       | 九幽冥主 |
| 太虚天境 | 10 分钟      | 太虚劫灵 |

六境倒计时合计 45 分钟，妖王战和升级选择时间另计。三档难度为初入仙途、问道试炼、天劫降临，后两档提供更高的灵石与修为收益。

六个秘境分别使用苔石竹径、赤砖残墟、冰雪岩面、泥沼根系、幽冥荒土和金纹云台的独立地面素材；选关预览与实际战斗同步切换。

永久境界：炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫，各分初、中、后期。灵石可提升气血、攻击和身法；玄铁配合灵石可把法宝永久炼至五阶。斩妖和局内升级的修为实时入账，满额立即突破，每次气血 +3、法宝伤害 +2.5%，当局生效。通关额外修为、灵石、玄铁在结算时发放；失败也结算收益。

局内 LV 代表选技等级，新局重置；境界按永久修为增长。修为总额仍为 `floor((斩妖数 × 0.7 + 局内等级 × 8 + 通关奖励) × 难度收益倍率)`，实时发放部分在结算时扣除，不会重复领取。

## 存档

使用浏览器 `localStorage`，键名为 `qinglan-immortal-v1`。

- 永久进度在突破、修炼、炼器、设置变更和结算时保存；AI 代打与修行路线也会保留。
- 旧存档默认兼修；已开始对局锁定原路线，更新前已有的跨流派法宝保留。大厅切换路线只影响新局。
- 进行中对局每 5 秒保存，暂停、升级选择、离开页面时也保存。
- 恢复包括角色位置、气血、法宝、功法、敌人、弹道、掉落、时间、三选一和重悟次数。
- 恢复后先暂停；升级中的存档保留原有选项，开启代打时会自动选择。
- 永久修为与本局已入账数额在同一个存档中保存。旧版未结束对局读取时补发已有战绩的修为，连续刷新不重复补发。放弃旧局时保留已入账修为。
- 永久收益与结束本局存档在同一次 localStorage 写入中完成，刷新不会重复结算。
- 本机存档按浏览器、设备和网址隔离。清除网站数据会删除存档；没有账号或云同步。
- 浏览器异常终止时，当前局最多可能回退到上一个 5 秒检查点。

## 项目结构

| 文件                 | 职责                                  |
| -------------------- | ------------------------------------- |
| `src/data.ts`        | 法宝、功法、妖物、秘境、难度数据      |
| `src/game.ts`        | 独立于 DOM 的战斗模拟、选技、对局快照 |
| `src/autoplay.ts`    | AI 走位与选技策略，游戏和难度模拟共用 |
| `src/render.ts`      | Canvas 场景、角色、弹道与特效         |
| `src/item-art.ts`    | 法宝与功法共用的生成图集映射          |
| `src/sprites.ts`     | 战斗和妖物志共享的立绘图集映射        |
| `src/progress.ts`    | 永久境界、资源、炼器、修炼与结算      |
| `src/main.ts`        | 页面、输入、音效、存档、游戏状态衔接  |
| `src/guide.ts`       | 游戏内修行指南                        |
| `src/style.css`      | 桌面和移动布局                        |
| `tests/game.test.ts` | 逻辑回归测试                          |
| `scripts/balance.ts` | 可复现的自动战斗和成长模拟            |

使用 TypeScript、Canvas 2D 与 Vite，不依赖运行时游戏框架或后端。开发模式提供 `window.__qinglan` 以验证场景，生产构建会移除该入口。中文字体优先使用 Noto Serif SC，加载失败时回退到系统宋体。

图片为本项目通过内置 imagegen 工具生成，已保存于 `public/assets/`。生成提示词见 [素材说明](docs/assets.md)，测试范围与限制见 [验证记录](docs/verification.md)。

## 开发时保护正在运行的游戏

有人正在游玩时，使用独立工作树和独立端口迭代；不要对游玩服务的源文件触发热更新。新增素材必须先落盘、检查所有路径可加载，再接入资源清单，并通过 Chrome DevTools MCP 验证。不同端口的 localStorage 相互隔离，测试端口不会继承游玩端口存档。
