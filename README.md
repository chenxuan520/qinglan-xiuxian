# 叩仙门：青岚纪

![叩仙门：青岚纪 · 晨光云海与烟火人间](public/assets/qinglan-prologue.webp)

> 山河未老，故人先秋。此去青岚，愿你历尽千劫，仍记得为何出发。

**[立即游玩 · 官方网站](https://xiuxian.011203.xyz/)**

御三十六法宝，闯七重秘境，在流逝的岁月里叩问长生。

## 仙途一览

- **法宝与功法**：36 种法宝、16 部功法，正道稳健、魔功有得有失，十阶炼器与仙器觉醒，妖王遗宝自动入库。
- **七重秘境**：地域妖物各有分工，前六境精英具备主动技能；前六境 3 / 3 / 4 / 4 / 5 / 5 分钟，终境每分钟一王，第七分钟迎战仙尊；成为真仙后可叩入仙门，为此世落幕。
- **修行与人间**：五行命盘、灵根轮回、寿元、仙途履历与灵威，百年城景变迁、三代炉火旧事、凡人道侣与故人来信、AI 闲谈与茶馆听书、拜入宗门，研习与委托直接消耗年岁结算。
- **丹香入道**：28 种战前丹药、十年轮换药铺、每世随机药方，耗费年岁合成，偶遇永久丹缘。
- **随时入境**：支持电脑、手机与 AI 代打，本地存档可导出、导入。

电脑使用 WASD / 方向键，手机拖动走位，横竖屏跟随设备与系统设置。完整玩法见游戏内「修行指南」。

## 本地运行

需要 Node.js 22.18+。

```bash
npm ci
npm run dev -- --port 5173 --strictPort
```
