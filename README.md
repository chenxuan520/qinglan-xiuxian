# 青岚仙途

![青岚仙途 · 晨光云海与烟火人间](public/assets/qinglan-prologue.webp)

> 山河未老，故人先秋。此去青岚，愿你历尽千劫，仍记得为何出发。

**[立即游玩 · 官方网站](https://xiuxian.011203.xyz/)**

一款修仙题材的 Web 幸存者游戏。操控走位，法宝自动攻敌，从炼气一路问道长生。

## 仙途一览

- **法宝与功法**：36 种法宝、16 部功法，正道稳健、魔功有得有失，十阶炼器与仙器觉醒，妖王遗宝自动入库。
- **七重秘境**：妖物、精英与妖王层层进阶，前六境 3 / 3 / 4 / 4 / 5 / 5 分钟，终境每分钟一王，第七分钟迎战仙尊。
- **修行与人间**：五行灵根、寿元轮回、仙途履历与灵威，百年城景变迁、三代炉火旧事、AI 闲谈与茶馆听书、拜入宗门，研习与委托直接消耗年岁结算。
- **随时入境**：支持电脑、手机与 AI 代打，本地存档可导出、导入。

电脑使用 WASD / 方向键，手机拖动走位。完整玩法见游戏内「修行指南」。

## 本地运行

需要 Node.js 22.18+。

```bash
npm ci
npm run dev -- --port 5173 --strictPort
```
