# 青岚仙途

一款青绿色仙侠风的 Web 幸存者游戏。只需操控走位，法宝自动攻击；斩妖、拾取灵气、搭配功法，从炼气一路修至渡劫。

## 本地运行

需要 Node.js 22.18+ 和 npm。

```bash
npm ci
npm run dev
```

打开终端显示的地址，默认是 `http://localhost:5173`。手机与电脑在同一局域网时，可使用终端显示的 Network 地址访问。

```bash
npm test           # 战斗、成长、存档与立绘映射测试
npm run build      # TypeScript 检查与生产构建
npm run preview    # 预览 dist 中的生产版本
npm run balance    # 固定种子的难度与六境连续战斗模拟
npm run balance:trial # 四档境界的终关挑战模拟
npm run format:check
```

## GitHub Pages

在线游玩：[青岚仙途](https://chenxuan520.github.io/qinglan-xiuxian/)。

`.github/workflows/pages.yml` 在推送到 `master` 时执行格式检查、测试与生产构建，再部署到 GitHub Pages，也支持在 Actions 页面手动运行。仓库 Settings → Pages 的发布来源需设为 **GitHub Actions**；私有仓库需要支持 Pages 的 GitHub 套餐。

构建会使用 Pages 提供的子目录路径，地图、人物、法宝图标和后台计时 Worker 均支持仓库地址下访问。本地 `npm run dev` 与默认构建继续使用根路径。

GitHub Pages 和 localhost 是不同来源，浏览器存档各自独立，不会自动同步。

## 玩法

- 电脑：WASD / 方向键移动，Esc / P 暂停，升级时按 1 / 2 / 3 选择。
- 手机：按住战斗画面拖动虚拟摇杆，松开停止移动。
- 「AI 代打」可在主页、战斗、暂停或升级界面开关：自动走位、避敌、拾取与选择法宝功法，优先配套和仙器进化。方向键 / WASD 或触屏移动会切回手动；切到后台仍继续走位、选技、拾取遗宝与保存；主动暂停和结算时停止。手动模式切屏自动暂停。关闭页面、系统休眠或浏览器冻结页面时不会离线代打。无需配置密钥。
- 点击音效按钮后可调节 0–100% 音量，支持静音，刷新后保留音量。点击空白处收起滑杆。
- 顿悟只有一个选项时直接领取；多项时才弹出选择。局内前 60 级保持原经验曲线，之后所需经验递增加速；100 级封顶，不再通过经验触发升级与回血机缘，击杀永久修为仍正常入账。
- 攻击自动进行。靠近灵气结晶自动拾取，升级时获得三选一，每局可重悟 3 次。
- 每局最多 6 件法宝与 4 种功法。法宝六重、配套功法三重后，可选择仙器进化。
- 前六境每 36–48 秒有精英妖物；倒计时结束后妖王出现，击败妖王才算通关。
- 右上角「?」为修行指南，包含操作、道具效果、全部进化配方和存档说明；战斗中打开会自动暂停。

## 内容

36 件法宝，正道与魔道各 18 件。新增古琴声浪、笔阵连印、驻地灵塔、三才阵旗、药鼎回复、追踪笛音、周身念珠、十字星线、玄伞消弹、贯穿长枪、残血斩镰、追魂连钉、棺落冥土、牵引长鞭、穿透骨灵、汲血池、蛊巢毒爆、裂镜分片、巨斧震退、错时落星。每件均有攻击特色与仙器觉醒。

16 种辅助功法，正道与魔道各 8 种。正道提供御剑、冷却、范围、护体、长生、暴击、聚灵和紫府成长；魔道提供增伤承伤交换、残血加速、命中减速、受伤骨刺、斩妖回复、暴击强化、击杀拘魂和逆命成长。完整数值和配方见游戏内图鉴。

每次出发前可选择正道、魔道或兼修。纯修只能选择本流派本命法宝，新领悟也只出现本流派法宝和功法；兼修自由混搭。正道最大气血 +12%（包含境界、根基和功法气血加成，四舍五入为整数）、持续回血速度 +20%，魔道额外法宝伤害 +12%，兼修没有额外路线加成。携带上限仍为 6 件法宝与 4 种功法。

觉醒条件为法宝六重、配套功法三重，再升级时优先出现「仙器觉醒」。每件法宝均有正、魔功法配方，兼修满足其中一条即可；纯修按当前路线配套。图鉴可按流派筛选，36 件法宝和 16 种功法的图标全部使用同一风格的生成图片。

72 种普通妖物、6 位独立造型妖王，以及全新最终首领「九天执劫仙尊」。前六境各拥有 12 种专属妖物，新地图不再刷新上一境的怪物；普通怪、精英和召唤物均来自当前秘境。每境 12 种妖物分四批，每批 3 种；前六境在开局、关卡时长的 25%、50%、75% 解锁，首境前 20 秒仅有菇妖。第七境提前到 0:00、0:45、1:30、2:30，两分半后全部高级兵种均可出现。后续新批次占自然刷怪的 65%，之前兵种占 35%，前六境后半场每波出现两只精英。前六境普通怪刷新量提高 25%，同屏自然刷新上限仍为 240；普通怪伤害为原来的 1.3 倍，精英为原来的 2.2 倍（精英此前与同种普通怪同伤害），六位妖王基础伤害依次为 52 / 68 / 84 / 100 / 116 / 132，再应用难度系数，碰撞、弹幕与区域技能均随之增强。第七境密度和伤害保持原值。新增 44 种地域进阶种，继承追击、远程、冲刺、重甲、自爆、召唤等行为，使用独立立绘并提高基础气血、伤害和经验掉落；后四境还保留各自的散射、环射、护盾、毒域等特殊妖物。旧版续局已在场的妖物保留，后续刷新按新规则。

前六境倒计时合计 33 分钟。第七境全部为精英，六位旧王在 1:30、3:00、4:30、6:00、7:30、9:00 按时登场，10:00 仙尊登场，共七位，上一位未击败也会继续出现下一位，最多七王同场。全部七位妖王被击败才通关，提前击败仙尊也必须清理其余妖王，妖王战和升级选择时间另计。终关不掉落回血丹，宝匣只提供法宝升阶和玄铁，不回复气血；旧续局地上的回血丹也会移除。终关精英有 6% 概率掉宝匣，妖王必掉；回春灵露回复 15% 气血，普通六境仍为 40%。三档难度为初入仙途、问道试炼、天劫降临，后两档提供更高的灵石与修为收益。

所有妖王在距离玩家超过 330 像素、追袭冷却结束时会发动「裂空追袭」：原地预警 0.85 秒，锁定方向后以 820 像素 / 秒冲刺 0.7 秒（574 像素），可侧向闪避。追袭间隔为 9 秒，半血后 6.5 秒；狼王的突袭和仙尊的一秒预警雷袭也使用长距离冲刺，冲刺期间不会被其他招式打断。

前六位首领各有三招，最终仙尊有六招：木王缠绕 / 荆棘 / 召唤，狐王炎扇 / 火径 / 火环，狼王突袭 / 冰矢 / 冰牢，毒君瘴池 / 毒矢 / 召唤，冥主召鬼 / 灵轮 / 鬼牢，劫灵十字雷 / 星环 / 陨星，仙尊雷轮 / 五方落雷 / 八荒封天 / 天罡剑潮 / 金阙天兵 / 踏云雷袭。仙尊基础伤害为 220，比之前提高约 16%；新增大范围扇形剑潮、六名精英天兵及带一秒预警的突进雷袭，召唤遵守同屏上限。半血后施法更快，落地攻击保留 1.2 秒预警。终关移除龟类和慢速重甲，保持全员精英。开局密度、速度、伤害及施法频率较低，后半程逐步加强；追击精英从第二批阶段开始追加冲刺，远程弹速与施法压力随时间提升。自然刷怪速率从约 0.9 只 / 秒渐增至 8.1 只 / 秒（普通难度、无 Boss 时），同屏小怪上限 210（Boss 另计）；Boss 出场期间自然刷怪为 70%。刷怪速度和小怪属性在第 10 分钟封顶，之后不会因为拖延而无限增长。

七个秘境分别使用苔石竹径、赤砖残墟、冰雪岩面、泥沼根系、幽冥荒土、金纹云台和归墟黑玉石的独立地面素材；选关预览与实际战斗同步切换。

封面角色周围的外观按九大境界变化：炼气灵气、筑基剑阵、金丹悬丹、元婴莲花与灵体、化神五行符印、炼虚星环、合体阴阳灵环、大乘万剑法阵、渡劫雷光。读档和轮回后按实际境界显示。

永久境界：炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫，各分初、中、后期。灵石可提升气血、攻击和身法；玄铁配合灵石可把已收藏法宝永久炼至十阶，每阶伤害 +8%，满阶 +80%。前五阶费用不变，第六阶起加速递增：升至六至十阶分别需要 30 / 69 / 132 / 219 / 330 玄铁，以及 440 / 1025 / 1970 / 3275 / 4940 灵石。已有炼器等级保留。默认收藏青霄剑与追魂钉，并解锁首位五行对应的正魔入门法宝；默认本命按灵根与路线确定，追魂钉仍排在魔道法宝第一位。每位妖王必掉 3 件未拥有法宝（不足 3 件则掉剩余数量），收齐后不重复掉。结算页或藏器阁拾取后才能设本命和炼器，AI 自动拾取；待拾取遗宝也永久保存。局内三选一不受收藏限制。旧存档的当前本命与已投入炼器的法宝保留为已收藏。斩妖和局内升级的修为实时入账，满额立即突破，小阶段突破气血 +3、法宝伤害 +2.5%；大境界突破气血 +45、法宝伤害 +35%，当局生效。同类加成相加，元婴初期的累计境界加成为气血 +153、法宝伤害 +120%。已有境界与旧对局自动获得新加成，续局保留已损失气血，重复刷新不会重复补发。通关额外修为、灵石、玄铁在结算时发放；失败也结算收益。

灵根具有金、木、水、火、土属性，天灵根与异灵根为单系，普通灵根包含 2–3 种、伪灵根包含 4–5 种不同五行，无灵根没有五行。每件法宝标注一种属性，灵根含有该属性时，法宝原伤害乘以对应加成；多系覆盖更广，但单系加成更低，不把多个属性加成叠到同一法宝。天灵根最高 +15%。资质仍影响局内经验、斩妖与 Boss 突破修为、通关修为，天灵根维持原速度。洞府「悟道」每阶法宝伤害按资质分别为天灵根 +5%、异灵根 +4%、普通灵根 +3%、伪灵根 +2%、无灵根 +1%；原有悟道等级不变，新局按所选资质计算。基础气血分别为天灵根 100、异灵根 95、普通灵根 90、伪灵根 85、无灵根 80，再叠加淬体、境界、功法与正道 +12%。基础回血依次为每秒 0.18 / 0.16 / 0.14 / 0.12 / 0.10 点；长生真经每重再加每秒 0.2 点，正道对基础与功法合计回血乘 1.2。旧续局按开局资质重算上限，保留已损失血量；不会因大厅洗根改变本局资质。

首次创建与轮回时随机资质及互不重复的五行，刷新和新局不重抽。旧档已有资质、修为与装备保留，双、三灵根改名为普通灵根，四、五灵根改名为伪灵根，首次读取补齐五行后保存；更早没有资质的旧档按天灵根迁移。

主页和洞府提供两个 5 秒「广告位招租」入口：自选灵根资质与五行，或领取 300 灵石、30 玄铁。灵根自选需要选满对应数量的不同五行，已选满时点击其他属性替换末位；已是天灵根也能重选，允许选择无灵根。领取后解锁首位五行的正魔入门法宝，并设置为当前路线本命；只影响之后的新历练，未完成的续局锁定原来的灵根与武器，不追溯补发修为。完整等待后点击领取即保存，中途取消不发放，同次只能领一次，物资可再次观看领取。轮回会重新随机资质与五行，可能变低。

局内 LV 代表选技等级，新局重置；境界按永久修为增长。每级门槛为原经验曲线乘以 `1 + max(0, LV - 60)² / 180`；80 级约为原先的 3.22 倍，99 级约为 9.45 倍。超过 100 级的旧续局恢复为 100 级，清除溢出经验和超限机缘，永久收益、装备和境界保留。修为总额为 `floor((斩妖数 × 0.7 + 强敌额外修为 + 局内等级 × 8 + 通关奖励) × 难度收益倍率 × 灵根倍率)`，实时发放部分在结算时扣除，不会重复领取。普通怪的修为按基础经验及地图阶数增加，精英为同种普通怪的 4 倍；Boss 突破奖励按秘境固定发放：前六境基础永久修为依次为 2500 / 5000 / 7500 / 10000 / 12500 / 24000；终关前六王各 18875，仙尊 62916，再乘难度收益与灵根倍率，击杀时实时入账，结算不重复发放。炼虚、合体、大乘的小怪修为按当前境界逐步折算减缓（初期分别除以 2、6、16，每小阶段再乘 1.15），不会扣减已有境界或修为；局内灵气不受影响。灵气按基础经验乘地图系数，精英为同种普通怪的 8 倍；Boss 直接吸收至少相当于本关最强精英 30 倍的基础灵气，下限为 `1200 + 地图序号 × 600`，再应用功法经验加成与灵根倍率，仍受 100 级上限约束。Boss 的永久突破奖励不受小怪的高境界折算影响，大境界成长以击败 Boss 为主。终关前六王的灵气可升级选技，结束战斗的 Boss 灵气计入最终等级与修为，避免散落场景无法拾取。

未通过第七境时，永久境界最多为大乘后期，超额修为继续保留。通关第七境解除渡劫瓶颈，达标即可突破；已有第六境通关记录的旧存档自动解锁第七境。旧档即使修为已达渡劫，也需破关才能恢复渡劫境界。

通关时播放约 3 秒的金色剑阵与灵光特效，第七境显示「七劫尽破」专属祝贺，随后自动展示战绩；点击「查看通关战绩」或按 Esc / P 可跳过。奖励在特效开始前保存，减少动态效果的系统设置会关闭动画。

死亡时可选择观看 5 秒「广告位招租」占位页，每局最多 10 次满血复活，并获得 3 秒无敌；可随时放弃复活直接结算。复活保留时间、敌人、法宝、等级和伤害统计，次数随对局保存；复活前不结算，避免重复领取收益。AI 不会自动替玩家观看广告，死亡后等待选择；10 次复活用尽后再次死亡直接结算。主动结束历练直接结算。

战斗顶部「伤害」与暂停菜单「伤害统计」可随时查看本局排行，查看时暂停；从战斗打开时关闭恢复战斗，从暂停菜单打开时关闭仍保持暂停。结算页也按伤害从高到低显示每件法宝的伤害与占比，觉醒前后的同一法宝合并统计，持续伤害和分裂、弹射、爆炸均归属来源法宝；骨甲反伤单列。仅计算敌人实际损失气血，减伤与击杀溢出不虚增占比。旧版续局的历史总伤害显示为未分类，新伤害正常追踪。

## 年岁与寿元

从 0 岁开始，仅实际战斗时间计龄，年龄跨局累计，包含 AI 后台战斗；暂停、升级选择、广告和离线不计龄。各境基础寿命：炼气 100、筑基 250、金丹 500、元婴 1000、化神 2000、炼虚 5000、合体 10000 年，大乘及渡劫无限。第一至第七境每分钟分别为 10 / 25 / 50 / 100 / 200 / 500 / 1000 年；例如保持炼气且未借寿，在第一境累计战斗十分钟就会寿尽。突破大境界立即增加寿命上限，年龄不重置；旧存档从本次更新起计龄，不追扣历史时间。

仅寿元耗尽时弹出「向天再借五百年」，可看 5 秒占位广告；主页和洞府只展示寿元，不提供提前借寿入口，每次增加当前大境界基础寿命的 30%（炼气 +30 年、筑基 +75 年等），并非固定增加 500 年，也不对已借寿元复利；每次寿尽都可再借，累计年数随突破、刷新和导出保存，大乘起无需借寿。寿尽时战斗冻结，可以广告续命，满血并获得 3 秒护体，先暂停等待继续，不占普通战斗复活次数；取消广告仍停在寿尽选择。放弃续命则强制轮回，清空全部进度、年岁、借寿和续局并重抽灵根。刷新无法绕过寿尽；手动轮回按钮在「此世灵根」卡片内，仍需确认。

## 存档

使用浏览器 `localStorage`，键名为 `qinglan-immortal-v1`。

- 永久进度在突破、修炼、炼器、妖王掉落、遗宝拾取、设置变更和结算时保存；灵根资质与五行属性、AI 代打与修行路线也会保留。
- 旧存档默认兼修；已开始对局锁定原路线，更新前已有的跨流派法宝保留。大厅切换路线只影响新局。
- 进行中对局每 5 秒保存，暂停、升级选择、离开页面时也保存。
- 恢复包括角色位置、气血、法宝、功法、敌人、弹道、掉落、时间、三选一、重悟次数、复活次数、法宝伤害统计、已出场与已击败 Boss 数量。死亡待复活的对局也会保存。
- 恢复后先暂停；升级中的存档保留原有选项，开启代打时会自动选择。
- 永久修为与本局已入账数额在同一个存档中保存。旧版未结束对局读取时补发已有战绩的修为，连续刷新不重复补发。放弃旧局时保留已入账修为。
- 永久收益与结束本局存档在同一次 localStorage 写入中完成，刷新不会重复结算。
- 「此世灵根」卡片内的「轮回转世」经再次确认后清空全部永久进度、待拾取遗宝和续局，只保留新角色默认法宝并重新随机灵根资质与五行；可取消，不影响其他网址的存档。
- 洞府「存档备份」可导出 JSON，包含全部永久进度与未完成历练；在其他设备或网址选择「导入存档」，校验后展示进度摘要，确认才覆盖。支持本游戏导出文件和旧版原始存档 JSON。取消、文件损坏、格式不兼容或浏览器写入失败不会覆盖当前进度，文件上限 10 MB。
- 前六境旧续局按原进度比例换算为缩短后的时长，精英时机一起提前，既有等级、气血与战利品保留；重复读取不再次压缩，第七境时间不变。
- 本机存档按浏览器、设备和网址隔离。清除网站数据会删除存档；没有账号或云同步。
- 浏览器异常终止时，当前局最多可能回退到上一个 5 秒检查点。

## 项目结构

| 文件                 | 职责                                  |
| -------------------- | ------------------------------------- |
| `src/data.ts`        | 法宝、功法、妖物、秘境、难度数据      |
| `src/game.ts`        | 独立于 DOM 的战斗模拟、选技、对局快照 |
| `src/autoplay.ts`    | AI 走位与选技策略，游戏和难度模拟共用 |
| `src/render.ts`      | Canvas 场景、角色、弹道与特效         |
| `src/item-art.ts`    | 法宝与功法共用的生成图集映射          |
| `src/sprites.ts`     | 战斗和妖物志共享的立绘图集映射        |
| `src/progress.ts`    | 永久境界、资源、炼器、修炼与结算      |
| `src/main.ts`        | 页面、输入、音效、存档、游戏状态衔接  |
| `src/guide.ts`       | 游戏内修行指南                        |
| `src/style.css`      | 桌面和移动布局                        |
| `tests/game.test.ts` | 逻辑回归测试                          |
| `scripts/balance.ts` | 可复现的自动战斗和成长模拟            |

使用 TypeScript、Canvas 2D 与 Vite，不依赖运行时游戏框架或后端。开发模式提供 `window.__qinglan` 以验证场景，生产构建会移除该入口。中文字体优先使用 Noto Serif SC，加载失败时回退到系统宋体。

图片为本项目通过内置 imagegen 工具生成，已保存于 `public/assets/`。生成提示词见 [素材说明](docs/assets.md)，测试范围与限制见 [验证记录](docs/verification.md)。

## 开发时保护正在运行的游戏

当前按用户要求直接在 master 迭代，5173 使用生产预览。有人正在游玩时，不重启或热刷新游玩服务；先构建到临时目录，发布时先补齐资源、保留旧 hash 文件，最后原子替换入口 HTML。不要直接清理正在服务的 dist。新增素材必须先落盘、检查所有路径可加载，再接入资源清单，并通过 Chrome DevTools MCP 验证。不同端口的 localStorage 相互隔离，测试端口不会继承游玩端口存档。
