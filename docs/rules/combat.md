# 战斗、妖物与按需模块约定

> 改动妖物、地域技能、妖王招式、战斗公共类型、HUD 或指南/履历按需加载前通读。本文件由 AGENTS.md 拆出，条文为用户已确认的约定，修改须经用户同意。

## 地域技能、妖王招式与控制效果

前六关小怪地域技能在 `regional-combat.ts`，妖物志技能说明在按需加载的 `regional-skill-info.ts`，危险区几何与自动走位共用 `regional-hazards.ts`，绘制在 `regional-render.ts`。条形区域用带圆端的线段判定，漂移仅在预警结束后开始，小怪瘴云持续4.8秒，妖王保留五处固定瘴池、持续5秒，第四境原生毒君的漂移毒瘴与追云持续12秒、速度分别为72与96；终关劫相保留6秒及24与32的漂移速度；小怪完整区域及漂移不得越过施法者周围 200 像素。第二至第六境普通、精英与妖王出生伤害统一额外乘1.1，妖物志共用enemyCombatStats；不在弹丸/地面招式重复乘入，首境与独立天劫不乘此项。所有秘境及终关的妖王必须保留data.ts原招，六位旧王保留原三招并各追加用户已认可的第四招（木心、回焰、双狼、原漂移毒瘴、逆行魂影、星珠），狼王两段连扑、毒君追云与冥主瞬移留假影及远距瞬移等非条带招式必须保留，仙尊原六招不改，不得替换原攻击形态；所有妖王条带攻击已撤，新增招式须先给用户看方案并获认可，不能擅自接入。招式池与间隔在boss-skills.ts，原冷却统一乘0.85，半血在原加速基础上再额外乘0.85并按毫秒取整；前六境2.55／1.337秒，终关旧王1.87／1.084秒，仙尊1.53／0.795秒（常态／半血）。双王独立施法，不新增互锁或危险区重叠限制；原生第二、三、四境妖王气血在既有倍率上再乘1.2；伤害及出场排程不变。共用魂弹命中也施加封宝，旧圆形雷印不新增禁锢，修改共享战斗或自动策略时须验证这些边界。 第二关火球仅将原伤害两成拆为1.5秒灼烧，不额外叠伤、不叠层或刷新时长；护体不施加，暂停冻结，快照保存剩余伤害，复活/借寿清除。第六关错拍双雷路与雷痕使用独立kind，击杀施法者散阵，雷麻禁锢0.65秒，魂弹封宝1秒，两者各有1秒保护，不叠层或刷新；护体不施加，暂停冻结，续局保留，复活与寿尽借寿清除。封宝仅暂停法宝自动施放，已发出的攻击继续，移动不受影响；新的突进技能必须接入精英波兵种筛选，终关同种兵保留原技能。指南通过 `guide-source.ts` 按需加载，构建出的指南模块必须纳入离线清单；异步回调不得重新打开已关闭的面板。灵威/履历详情由 `chronicle-source.ts` 按需载入 `chronicle-content.ts`，同样遵守当前构建重试、离线缓存和迟到回调约束；增幅来源固定真实本命与路线，逐项移除重算且只读，不另抄战斗公式。

## 妖物志与敌人数值

妖物志的气血与触碰伤害必须通过 `enemy-stats.ts` 与实战出生共用计算，按所选难度、关卡及出现时段显示，不直接使用敌人模板基础值；普通和精英的同刻对照不表示所有兵种都会自然生成精英，守匣守卫另按七成气血说明。修改敌人数值模块须跑相关定向测试与840条快检，完整矩阵交每日定时执行。

战斗公共类型、续局校验与各模块分工见 [AGENTS.md](../../AGENTS.md)「技术与目录」，以该处为准。

竹海 `enemy-roots` / `boss-roots`（含终关旧王）改为藤缠，不再减速：持续3秒，期间所有掉落停止吸附与拾取且留在地上；当前效果不刷新，结束后另有1秒保护间隔。深泽毒圈、毒瘴及毒君弹的实际正毒伤造成3秒蚀体，每次有效毒伤刷新时长；护体挡住的不触发。蚀体完全阻止战斗回血，包括回春灵露、宝匣、斩妖、法宝区域回血与突破/恢复战况的正向气血补算；回春丹暂不吸附拾取，其他掉落正常。复活、寿尽借寿与新开天劫的恢复保留且清除两状态。两状态与藤缠保护时点纳入对局快照校验，暂停冻结；自动历练避开藤圈，控制期间不追不可拾取物。新提示仅在当前战斗实例首次触发各显示一次，活动状态续局不重复；不为提示新增持久字段。
