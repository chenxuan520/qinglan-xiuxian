# 战斗、妖物与按需模块约定

> 改动妖物、地域技能、妖王招式、战斗公共类型、HUD 或指南/履历按需加载前通读。本文件由 AGENTS.md 拆出，条文为用户已确认的约定，修改须经用户同意。

## 地域技能、妖王招式与控制效果

前六关小怪地域技能在 `regional-combat.ts`，妖物志技能说明在按需加载的 `regional-skill-info.ts`，危险区几何与自动走位共用 `regional-hazards.ts`，绘制在 `regional-render.ts`。条形区域用带圆端的线段判定，漂移仅在预警结束后开始，小怪瘴云持续4.8秒，妖王保留五处固定瘴池、持续5秒，第四境原生毒君的漂移毒瘴与追云持续12秒、速度分别为95与120、半径分别为75与70；终关劫相同为12秒及95与120的漂移速度和相同半径；小怪原落阵完整区域及漂移不得越过施法者周围 200 像素；用户指定的第三境冲刺冰路沿原209像素扑击路径铺设、圆端半径16，因此此冲刺路径允许最远225像素；第四境小兵漂移毒瘴按用户指定提速150%，速度由12改30，持续4.8秒、起点偏移75与半径50不变，完整漂移边界最远269像素。除此两项外不扩大其他落阵范围。第二至第六境普通、精英与妖王出生伤害统一额外乘1.1，妖物志共用enemyCombatStats；不在弹丸/地面招式重复乘入，首境与独立天劫不乘此项。所有秘境及终关的妖王必须保留data.ts原招，六位旧王保留原三招并各追加用户已认可的第四招（木心、回焰、双狼、原漂移毒瘴、逆行魂影、星珠），狼王两段连扑、毒君追云与冥主瞬移留假影及远距瞬移等非条带招式必须保留，仙尊原六招不改，并按用户确认追加万劫归一、天劫审判、归墟引力，不得替换原攻击形态；所有妖王条带攻击已撤，新增招式须先给用户看方案并获认可，不能擅自接入。招式池与间隔在boss-skills.ts，保留原冷却乘0.85与半血额外乘0.85的规则，在既有已取整到毫秒的间隔上再乘0.7并取整；初入仙途前六境1.785／0.936秒，终关旧王1.309／0.759秒，仙尊1.071／0.557秒（常态／半血）。独立追袭冷却同样乘0.7，常态5.355秒、半血3.287秒；地面预警、冲刺运动时长及施法保护下限保持；所有妖王冲刺蓄力减半，常规/追袭及狼王每段由0.85秒改为0.425秒，仙尊雷袭由1秒改为0.5秒。双王独立施法，不新增互锁或危险区重叠限制；原生第二、三、四境保留此前气血强化；在本轮基线32e711e上，第二境气血另乘1.2、第三至六境另乘1.1，首境与终关气血不变。所有原生与终关妖王基础移速在各自原有值上乘1.3，独立天劫不套用。伤害、首次出招等待及出场排程不变；续局保留已生成敌人的速度与剩余气血，不在恢复时重复强化。共用魂弹命中也施加封宝，旧圆形雷印不新增禁锢，修改共享战斗或自动策略时须验证这些边界。 第二关火球与小怪火径先造成完整直击，再额外灼烧3秒、追加本次火伤的20%，不叠层或刷新时长；灼烧时长与快照校验共用ENEMY_CONTROL.burn，清灵散不缩短灼烧；护体不施加，暂停冻结，快照保存剩余伤害，复活/借寿清除。冰谷冰弹、狼王弹与冰区统一减速25%、持续2秒，清灵散减半；生效期间不叠加或刷新，触发保护1秒，续局校验与持续时间共用ENEMY_CONTROL.slow。第六关错拍双雷路与雷痕使用独立kind，击杀施法者散阵，雷麻禁锢1秒，魂弹封宝2秒，两者各有1秒保护，不叠层或刷新；护体不施加，暂停冻结，续局保留，复活与寿尽借寿清除。封宝仅暂停法宝自动施放，已发出的攻击继续，移动不受影响；新的突进技能必须接入精英波兵种筛选，终关同种兵保留原技能。指南通过 `guide-source.ts` 按需加载，构建出的指南模块必须纳入离线清单；异步回调不得重新打开已关闭的面板。灵威/履历详情由 `chronicle-source.ts` 按需载入 `chronicle-content.ts`，同样遵守当前构建重试、离线缓存和迟到回调约束；增幅来源固定真实本命与路线，逐项移除重算且只读，不另抄战斗公式。

## 妖物志与敌人数值

妖物志的气血与触碰伤害必须通过 `enemy-stats.ts` 与实战出生共用计算，按所选难度、关卡及出现时段显示，不直接使用敌人模板基础值；普通和精英的同刻对照不表示所有兵种都会自然生成精英，守匣守卫另按七成气血说明。修改敌人数值模块须跑相关定向测试与840条快检，完整矩阵交每日定时执行。

战斗公共类型、续局校验与各模块分工见 [AGENTS.md](../../AGENTS.md)「技术与目录」，以该处为准。

竹海 `enemy-roots` / `boss-roots`（含终关旧王）改为藤缠，不再减速：持续3秒，期间所有掉落停止吸附与拾取且留在地上；当前效果不刷新，结束后另有1秒保护间隔。深泽毒圈、毒瘴及毒君弹的实际正毒伤造成3秒蚀体，每次有效毒伤刷新时长；护体挡住的不触发。蚀体完全阻止战斗回血，包括回春灵露、宝匣、斩妖、法宝区域回血与突破/恢复战况的正向气血补算；回春丹暂不吸附拾取，其他掉落正常。复活、寿尽借寿与新开天劫的恢复保留且清除两状态。两状态与藤缠保护时点纳入对局快照校验，暂停冻结；自动历练避开藤圈，控制期间不追不可拾取物。新提示仅在当前战斗实例首次触发各显示一次，活动状态续局不重复；不为提示新增持久字段。

二至五境普通与精英的原dash依次转换为firecharge、frostcharge、miasmacharge、soulcharge，并接入后期突进精英筛选；不改妖物气血、伤害、速度、原1.25秒蓄势及冰谷部分兵种额外0.3秒。第三境冰路长209、半径16、生效1.3秒，伤害倍率0.65，预警至冲刺开始；第四境只在真实冲刺结束的终点生成静止毒瘴，半径50、预警1秒、生效4.8秒、伤害倍率0.65，毒伤刷新3秒蚀体。第五境仅实际冲刺移动阶段接触触发封宝，普通接触/蓄势不施加，遵守护体与原保护。第一、六境及终关原技能映射不变，终关不新增冰路/终点瘴/魂冲或火径灼烧。续局沿已有charge/dx/dy及危险区恢复，无新增快照字段。

原生落霞古墟「九尾回焰」去返速度由155改为232.5，单程时长由1.15改2.3秒，单程距离178.25改534.75（原三倍）；预热0.8秒、转向停驻0.4秒保持，完整弹丸寿命5.8秒；原生与终关均每批七道、伤害为妖王的0.6倍，严格最多十四道。终关新回焰同为2.3秒/534.75轨迹和5.8秒寿命；已保存155速度的旧回焰与天劫事件保持原轨迹；轨迹、绘制箭头与自动走位共用同一时长判断，不新增存档字段。所有妖王召唤的战斗妖物至少标准精英强度，击杀按精英给局内灵气，沿用斩妖与修为结算，但不掉宝匣；召唤双狼不再压低精英气血/伤害，木心机关和假影仍不发经验。召唤物自然消散或随主人散去不结算，普通精英与普通小兵召唤物的原掉落规则保留。

独立天劫的前四劫参数保持原表。第五劫起以第四劫为基准：气血每劫乘1.5，到第十二劫封顶；基础伤害占玩家满血比例每劫增加5个百分点，最高100%；预警每劫减少0.1秒，最低0.1秒；出招间隔每劫减少0.3秒，最低1.2秒；反击窗口每劫减少0.3秒，最低0.65秒；每轮削血上限每劫减少2个百分点，最低3%。雷弹速度及招式数量/形态沿用原递进与封顶。自动历练的天劫绕行、核心距离及直线雷弹预测只作用于独立天劫；危险阶段不选站定等待，核心显露时兼顾近程输出，并预留撤离时间，不新增存档或快照字段。

九幽冥主原生基础气血倍率为2.4×1.2×1.1；摄魂灵轮二十发、速度200，百鬼召六只精英，六道鬼牢、基础触碰伤害倍率与冷却不变。原生与终关逆行魂影均为五道、伤害0.6倍、严格最多十道，依次蓄力1／1.35／1.7／2.05／2.4秒。幽影换形保留三具1气血幻影及本体换位150，幻影用现有圆形预警蓄力0.8秒后各放八发155速度、伤害为本体0.35倍的封宝魂弹并消散；提前击破或本体倒下则不放弹，不给收获。复用现有cooldown与windup计时，续局直接散去幻影，已发魂弹保留，不新增存档字段。狐王炎扇为200／145速度的9＋8发错位两层，轮舞为180／130速度的20＋20发两环；五点火径不变。

仙尊招牌技排在原六招之后，索引6/7/8；半血前抽到8时消耗原队列位置、改施6并按万劫归一播报。万劫归一均匀借前六王第四招，try/finally恢复bossStage=6；新增弹区与召物描边为#e8d69c，沿用施放者伤害及原机制上限。双狼每只气血至少施放者最大气血的8%，原生、终关与借用均适用，木心按同类型精英怪气血生成，仍不移动、不攻击、不计精英数量且击碎不提供收获。天劫审判每次施放独立留下3秒劫印，到期按玩家当时位置和input×65×i落三道半径60、0.8/1.2/1.6秒预警、1.2倍伤害的紫雷。归墟引力半血后持续2秒，叠加自身移动后每秒朝施放者拉90像素，不穿过施放者、不额外结算接触伤害，定身时不拉；0秒及1秒各24发速度170、0.75倍伤害的环弹。两类绝对战斗时刻纳入敌人快照、严格校验和深克隆；天劫中断未执行战斗的那帧顺延新计时，暂停/选技冻结，仙尊死亡或战斗结束即清除。自动历练仅在引力中给既有最终方向加权重1的背离单位向量再归一，零向量时直接背离，其余AI保持。

问道与天劫仅加强第二、三、四、六境原生妖王：常规出招间隔乘0.9／0.8，castBossSkill的fan及经fan生成的ring弹速乘1.1／1.2。基础bossSkillCooldown与追袭冷却不改，冲刺保护等待仍适用；castBossMechanic的回焰、魂影、星珠特殊弹速不乘，地面预警与时长不改。第一、第五境、终关及独立天劫不叠加；初入仙途在第二、三、四、六境也叠加间隔×0.9与弹速×1.1，并把同四境普通妖物与精英的血量、伤害分别乘1.15／1.2／1.25／1.2；妖王伤害沿用原难度damage倍率，不额外增加；普通与精英、妖王气血和奖励保留。终关旧王另在 trialHp 基础上按 trialKingHp 对狼王、毒君、冥主、劫灵分别乘 1.3／1.4／1.25／1.25，苍木、狐王、仙尊为 1。
