# 根基、寻访与宗门专长约定

> 改动根基修习、法宝寻访、宗门专长、献器献丹或拜入宗门前通读。本文件由 AGENTS.md 拆出，条文为用户已确认的约定，修改须经用户同意。

## 根基、寻访与宗门专长

根基价格与有效阶数集中在 `training.ts`，前五阶价格、前十阶收益保留；调整时必须比较同预算真实训练和合法满阶实战，不能仅用无训练快检证明养成平衡。指定法宝寻访在 `artifact-seeking*.ts`，物品概率和逐次成败在 `seeking-chance.ts`；报价每十年轮换，概率和费用须在办理前明示，失败也扣本次费用/年岁/额度，绝不能写成寻得或保底；次数持久化并按本世种子和物品固定该次结果，换入口、刷新或保存失败重试不得重抽。宗门专长在 `sect-service*.ts`，共用 `service-preflight.ts` 预留全部跨期供奉；法器阁与执事堂托付共用十年额度，所有宗门专长另共用十年额度，换宗不重置。宗门服务随原坊中事务模块按需加载，迟到回调、广告返回、保存失败回滚及手机横竖屏都须实测。不得借专长绕过原根基、精研、丹方与境界门槛。悟道后十阶使用独立收益曲线，不改变淬体/身法；献器与献丹按足额用完一次抵价的最少连续阶数结算，抵价不抵供奉，逐阶时间向上取到0.1年后相加，受境界/满阶限制用不完则零消耗拒绝，五/十阶精研赐丹不得跳过或重复。

## 拜入宗门赠药

成功付费拜入宗门随机赠一枚凡品丹药，与入门扣费、身份和见闻同次保存成功后应用；失败或重复点击不发药，未结束的历练不补发功法。
