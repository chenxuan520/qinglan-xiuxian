# 后端、统计、调试与平台行为约定

> 改动 NPC Worker、匿名统计、调试入口、公开监控、资源加载失败处理、留影或手机方向/镇坊快捷前通读。本文件由 AGENTS.md 拆出，条文为用户已确认的约定，修改须经用户同意。

## 后端与运营

- NPC 域名、模型、超时、对话长度与换代年限集中在 `src/setting.ts`；姓名与换代在 `src/town-population.ts`，百年城景和上次入城记录在 `src/town-history.ts`，对白 UI 在 `src/npc-chat.ts`，共享协议与兜底在 `src/npc-dialogue.ts`。Worker 在 `workers/npc-ai/`；修改后执行 `npm run check:npc-ai` 与相关测试，`npm run deploy:npc-ai` 单独发布。默认域名 `qinglan-npc-ai.011203.xyz`，绑定和 CORS 来源随配置维护；严禁将 API 密钥放入前端，AI 文本不能改变游戏数值或当作 HTML 执行。
- 匿名游玩统计在 `src/telemetry.ts`，经同一 Worker 的 `POST /event` 写入 Analytics Engine（`qinglan_events`），只在官网与 GitHub Pages 发送，静态部署不依赖它；`npm run stats` 查询。改事件字段需同步 Worker 校验、查询脚本与 [开发与部署](../development.md)。发布时先部署 Worker 再推送；上线验证写入的记录用版本号 `verification`，不要用真实版本号制造测试数据。
- 物资调试入口隐藏在「关于」版本号七连点（七秒内），不在设置或首页增加显眼入口。`GET /debug/access` 由 NPC Worker 的 `DEBUG_MODE_ENABLED` 决定，未配置时默认关闭；仓库不声明该变量，普通 Worker 发布使用 `--keep-vars` 保留线上开关，只有显式 `--var DEBUG_MODE_ENABLED:true/false` 才切换；只有明确字符串 `true` 开放，入口与每次发放都重新联网核验，不缓存许可，断网/超时/异常一律拒绝。调试直接使用当前存档，可发灵石、玄铁、法宝及炼器阶数、丹药、奇物，也可增加指定整数永久修为或补足到指定境界。修为调试只增加、最高渡劫（累计 `IMMORTAL_CULTIVATION` 且未通终关），超额拒绝、不截断，不添加通关记录或真仙，突破年表与大乘天劫时钟沿用真实进度函数；不自动改本命或服药，不允许未完历练、已落幕或劫修遭遇中发放。沿用 clone→writeSave→apply，保存失败及关闭面板后的迟到响应不得生效；成功后关闭本机匿名统计。开关部署及验证见开发文档。
- 统一公开监控入口 `/monitor/` 在两站「关于」中，公开聚合接口 `GET https://qinglan-npc-ai.011203.xyz/monitor/stats`（留影保存、分享与二维码来源在 `sections.sharing`），服务端凭证不得进入前端；`MONITOR_PUBLIC=false` 关闭线上公开查询。CI 诊断及每日渲染 / 模拟 / 体积摘要从 GitHub Pages 动态读取，性能 JSON 位于 `monitor/performance.json`，每日渲染只保留数值报告，不生成、保存或发布采样截图；逐项标明时间与源提交，失败或缺数据不能冒充成功；只发布 artifact，不提交生成报告或截图，详见 [开发与部署](../development.md)。

## 自营图片广告

- `workers/house-ads/` 独立部署、D1 保存投放，`https://xiuxian.011203.xyz/ads/admin/` 使用指定账号的密码登录，密码只保存带盐派生校验值，会话使用安全Cookie；新登录使用Turnstile并在服务端严格核对success、ad_admin_login动作及当前管理站点精确hostname，缺配置/失败不放行，组件失败或过期可原位重试；已有8小时会话继续有效。退出、改密撤销会话，写操作同源校验；取消登录共享global额度，保留按可信IP散列的10次/15分钟失败和并发名额，成功/服务故障释放；公开投放不携带管理凭据。后台将全局投放方式与Google参数明确分区，接收电脑/手机图片、共用跳转链接、四个既有广告位和两端各自0～1000整数权重；某端0不投该端，正权重该端HTTPS图片必填，任一正权重共用HTTPS跳转必填，两端0链接可空，非空链接始终校验。旧单权重及原实际手机图在后台预填到双端，新格式不以电脑图替代正权重的空手机图。每次观看固定同一渠道抽取和选图，转屏不更换渠道，旧请求缺device以UA/Client Hint识别；当前供给、Google发布商ID、测试模式和四个广告位名称也在同一后台统一配置，不接受脚本、HTML或奖励配置；每条广告可收起/展开，折叠不丢字段，校验失败自动展开定位；保存前浏览器实际加载非空图片，服务端复核公开HTTPS图片响应，失败拒绝保存且不改revision。版本冲突及保存失败须保留草稿且不能报成功。登录页仅head元数据提供agent API发现提示，公开OpenAPI及Markdown契约不含账号、配置或指标；agent复用同一密码会话、Origin和revision保护，不新建鉴权通道。管理账号、密码和会话不写公开仓库；官网路由`/ads/*`、`/ads.txt`、玩家公开入口`/api/reward-content/*`及匿名加载故障入口`/api/client-status`至广告Worker，部署用`--keep-vars`。
- 首页空闲时可按当前端预热配置、模块和最多4张有效素材；不预先申请统计凭条、不计曝光或开启观看，省流量模式跳过。图片广告仅在玩家主动打开广告面板后播放，电脑与手机均用覆盖游戏视口的5秒广告层，图片完整显示不裁边，底部仅显示倒计时和关闭按钮，关闭保留原放弃语义；有效观看完成自动收起回原奖励页，取消或故障也须释放覆盖层和原面板锁定。前台有焦点且图片至少半数可见时累计观看；点击图片另开页面不发奖励。取消、关闭、导入及过期会话结果不得生效；失败/无投放沿用原占位规则。奖励先成功写入再应用，失败可重试但不能重复领取。保持极限限制、Google 适配器和单机零后端请求；帮助分类仍不得出现广告说明。部署与接口见 [开发与部署](../development.md)。

- 各广告的请求、展示、点击、看完、成功领取及比率仅在已登录广告后台展示，按北京时间今天/7天/30天查看；普通游戏与公开监控不展示。仅在实际打开广告面板后申请统计凭条（空闲预热配置不签发凭条），同次打开的同类事件去重；领取仅在存档保存成功后记录，统计失败不影响奖励。Google点击、收入不伪造，以官方报表为准。统计凭条在写D1前按边缘IP哈希共用原生频控（同机房约60张/60秒，自营/Google及全部位置设备共额），超限、缺可信地址/绑定或异常只停止新凭条，仍返回广告且不影响原观看/领奖与已有凭条；共享IP可能少记，机房间计数独立且近似，不作为严格配额。预览及`verification=1`验证流量不计入运营汇总；不上传存档、玩家身份或管理凭据，指标不作结算依据。根域及官网ads.txt共同读取D1的Google配置，不保留分散的活动发布商ID。

## 资源加载失败

资源加载失败统一通知 `update-check.ts`，只有最新清单确认构建不同才显示「游戏已更新」，断网/同版/坏清单沿用原重试说明；不自动刷新、清缓存或删除存档。已处理的加载失败使用 `resource-panel.ts` 在原界面显示操作：尚未进入的场景只留一个「重新加载」，指南、履历等面板保留重试与刷新；版本结果只更新该处文字，不另叠故障弹框；关闭或切换后迟到结果不得重开。刷新必须先 `persist()` 返回成功，存档锁定、未结胜局或保存失败均留在页面。`module-source.ts` 合并并发并保留失败重试，重试只使用当前构建固定清单。指南与妖物志共用 `GuideSource` 按需载入，关闭、换分类和存档锁定后迟到回调不得重开面板。

## 此世留影

留影本命炼器信息下方展示生成时spiritPower真实score，沿用formatNumber显示万/亿小数，以淡金小字保持层级，不另抄灵威公式或改变其含义。留影直接异步编码 PNG Blob，不经 base64/逐字节映射重建文件；预览 URL 在面板关闭或替换时释放，Canvas 编码结束清零。图片下载保留独立的延时释放 URL，不因关闭预览中断下载。关闭后的迟到编码或素材回调不得重开面板；素材失败最多自动重试一次，取消不计为加载失败。 留影模块尚未加载就失败时只给一个受保护的「重新加载」（refresh-game），不能把缓存的失败import包装成无效「重新生成」；只有素材或编码阶段失败才允许原地重新生成。CI浏览器门禁须验证手机冷页断网→恢复联网→保护保存后重新加载→成功留影。

## 手机方向与镇坊快捷

手机方向设置由mobile-display.ts按需加载orientation.ts，使用独立本机键qinglan-screen-orientation，缺省跟随系统；不改变游戏存档结构或清除续局。方向锁定失败须明确提示，不能把触屏模拟或API夹具当实体手机验证；跟随系统、退出全屏及迟到结果均释放本游戏的方向锁。镇坊快捷按钮与路口共用settlement-travel.ts，按钮仅豁免路口距离，不得绕过境界、离乡、场景就绪、供奉、寿元、天劫或先保存后切换；正常快捷回镇从故居落地，路口仍用安全落点；场景所有入场入口须把路口触发/复位区内的旧坐标归到安全落点，不能仅给步行入口加保护。

- 广告慢请求每次含正文最多6秒，瞬时网络/超时/5xx仅重试一次，整轮加载上限30秒；等待时显示加载状态，无投放仍显示“广告位招租”。失败阶段通过独立只读管理诊断查询，按UTC日聚合版本、位置、端、浏览器族、阶段、有限错误类型、状态码与耗时；不收集原始IP、完整UA、链接、异常原文、存档或凭据。诊断单独边缘限流约30次/分钟、封闭字段且正文上限512字节，失效静默丢弃，不影响奖励。正常无投放与玩家取消不记故障；可见浏览器族不能证明实际Via设置或拦截原因。客户端缺响应流/TextDecoder时可用原生text兼容读取，前检已知长度、读取后复核UTF-8大小；Worker请求仍严格逐块限制。诊断记录已收到的真实HTTP状态，并区分读取/空正文/HTML/JSON/schema/超限，保留旧invalid；新公开入口非JSON且缺公开服务标记时用unexpected-response，标记不承担鉴权。只有真实无投放显示招租，故障显示简短失败与原位重试；重试作废旧观看轮次，不改变原奖励和占位兜底规则。
