# 《青岚纪·不系舟》创作说明与设定索引

> 本文含全书情节与结局。想先读故事，请打开[小说正文](novel.md)。天地原理与系统对应另见[世界观设定稿](worldbuilding.md)。小说已通过帮助「山河旧闻」中的入口接入独立阅读页；本说明仍供作者核对，不进入阅读正文，也未接入人物闲谈或留影生成。

## 这是谁的一生

陆迟是青岚镇一个船工家的孩子。他想修仙，最初既是想看看山外，也是想成为别人可以放心依靠的人。他真正的毛病藏在后一个愿望里：别人一有难处，他就先答应；自己肯冒险，便以为足够替同行担保。

故事写他怎样为这种习惯付出代价，也写他在债偿不了、人回不来的时候，仍然愿意修行。成仙不是给他免去责任的一张凭据，责任也不该成为禁止他再走一步的枷锁。

陆迟、施望初、姚霁与折火道旧案是本篇小说新增的人物、事件。它们构成这个世界里一种可能的人生，不规定每位玩家都曾经历。既有的青岚、宗门、器法、秘境与终章边界继续成立；游戏原有序章、终章及固定故事没有因这部小说改写。

## 六卷各自要完成的事

| 卷次 | 人物面临的事                                               | 叙事重心                                                   |
| ---- | ---------------------------------------------------------- | ---------------------------------------------------------- |
| 一   | 承诺带同伴走一条自己并未弄清的路                           | 少年互助、入门的新鲜感、第一次失信，以及尚来得及吃的家常饭 |
| 二   | 明知勘路图的「待验」被删，仍收下续勘的钱，想先补完路再澄清 | 落霞的火、护送的退路、许停舟的选择、归乡与证言生意         |
| 三   | 要揭穿经营者，便得承认自己与朋友也参与了误导               | 冰谷与毒泽的不同走法、离宗兼修、寻访与私邀的风险           |
| 四   | 知道旧事故的原因，仍须在眼下亲手作出舍弃                   | 九幽的残响、当代救援、有限的追偿，以及活着承担之后的生活   |
| 五   | 旧事已经了结，接下来究竟还想做什么                         | 太虚修行、器作的新一代、长生的乐趣，以及两个朋友各自的道路 |
| 六   | 已经能长久留世，是否仍愿走向真正未知的天地                 | 归墟七劫、成仙后的人间、告别与赠物                         |

旧案在第四卷结束。太虚与归墟不会再揭出一位暗中操纵它的更大凶手。仙尊不替陆迟裁定旧账，最终胜利依靠他此后真正练成的本领。

两次过错不作同一场重演：第一次是尚不懂承诺的分量，第二次已经知道界限，却为报酬、体面和补救的侥幸迟迟不肯澄清。施望初的怨恨不因最后一顿饭消失，陶辛也不因救命之恩放弃应得的赔偿。

姚霁有自己的器作、同伴与行程。两人可以明确相爱，同时不愿放下各自的路；她希望他留下、也仍会难过，不必以通情达理替他的离去作结。归墟中她的独立视角保留人间的日常与代价，既不替陆迟看见战况，也不预知他能否回来。

终战的残伞承接第三根伞骨的旧伤、雷毁歇脚棚与最后一块合用材料的损失，不靠休整恢复成完好的器物。末章在陆迟入门前以姚霁所赠饼的余温收束他的告别，仙门之后仍留给孟辛：问路、护玉、挪开扇柄，带着帮助继续走自己的路。栗子只尝一颗，纸包仍由少年带走，不另添一场传承。

修订版2补入初读所需的天地与修行常识：灵潮兴衰随渡口问话出现，功法、器式与炼器借入门和修剑分清，秘境里的年月由补给、练习与养伤承担。药母与成丹、承流件的受力关系服务旧案；寿限在突破和分别处交代，归墟前再分清地域妖王、周期天劫、成仙与离界。定稿收短第二章的集中讲解，将第十四章的神识与第三十五章的道痕说明放回陆迟的感受和查阅之中，保留人物关系、事件次序和结尾。

炼气至合体的总寿限依次是100、250、500、1000、2000、5000、10000年；突破提高总寿限，不把已经活过的年月归零。大乘自然寿数无尽，仍会在战斗中死亡。陆迟6800岁进入大乘，其独立的两万年周期天劫最早在26800岁；本书结束前不安排这场天劫，避免与太虚、归墟混淆。

姚霁比陆迟年长58岁，施望初小1岁。姚霁在筑基、金丹、元婴、化神、炼虚、合体与大乘之间的进境都有对应的经历和寿数空间；她不是因需要陪伴主角而被默认为不老。宋既明、温照川与许停舟的亲属也不在后世原样重现。传人可以继承手艺与记录，不能继承从未亲历的共同记忆。

## 折火道究竟发生过什么

这是一桩地方旧案。折火道属于落霞旧炉附近的运载与撤离设施，不是贯通七境的另一条秘密地图。竹海抄图与古墟运载图各有自己的地理范围；相似的是使用它们的人都把一部分真实经验当成了全程保证。

旧事故发生在陆迟启程前约六百年。十三匣对应旧炉的炉次与器位，不新增十三种游戏丹药。真封签证明容器的来历，封签早于开炉，不能证明里面曾经炼成过丹。损毁药母与未成丹残料也不能证明游戏中的成品丹药会自然过期。

事故中，维护欠缺、退潮、载荷与保货的坚持相互叠加。燕知雨切断承流，救出九人，三人未归，燕本人也在其中。她的最后选择救了人，不代表此前所有判断都正确。褚弥是逃出的九人之一，留下的笔记包含不能继续尝试的情形。顾南槐曾在外层撤离，后来签署了将过程简化为“魔修劫货”的记录；他的签名要负责，他的见闻却不能填满所有空白。

现世的杜衡利用这些真物、真印与局部成功出售希望。陆迟和施望初也不能只把自己放在受害人的位置：他们说过的话、隐去的疑问、收取的钱，确实影响了后来者。程述没有参加原事故，也不是杜衡的幕后主人；他的真实本领与对重建过分乐观的判断同时存在。

结案依靠当代撤离中的实际取舍、不同来源的材料、活人的陈述与能重复的小规模检验。九幽留下的一句操作残响不是可供无限盘问的死者。没有查明的最后时刻仍留空白；追回钱财、纠正名声和挽回生命是三件无法互相代替的事。

## 器物为什么有分量

青霄剑陪陆迟从起步走到离界。它的价值包括他真正学会怎样使用它，而非每逢遇险就换出一件未曾铺垫的新神器。九霄雷符、玄天伞与摄魂镰让不同器式和正魔取舍进入行动；正文不按图鉴把所有法宝逐一领齐。

玉如意来自一次不能保证成功的机缘。它减轻伤害，不免去受伤、错误与岁月。陆迟这一世没有反复获得、出售再买回同一件奇物；最后留给少年的也只有这一件。少年得到帮助，没有接收前人的境界、整套物资、人情关系或必须完成的遗愿。

掌天瓶与天机屋不充当补洞工具。前者不能包办所有制作，后者不能停止亲人的衰老；小说也不借新奇物解决旧设定中不存在的复生办法。

## 将来若用作游戏知识

小说现已提供独立阅读入口；下列提取方向仍供讨论，尚未建立人物闲谈或留影生成的知识依赖。

| 可以提取的内容                     | 适合知道的人               | 使用时要留下的界限                                   |
| ---------------------------------- | -------------------------- | ---------------------------------------------------- |
| 青岚的河运、做工与镇中日常         | 镇民、商贩、船家           | 只能讲当地生活，不自动认识每位玩家的亲人             |
| 纳灵效率、临战周天与永久道基的区别 | 教习与实际有相应见识的修士 | 用小段回答眼前问题，数值继续由当前游戏规则提供       |
| 器式与器物、本命与配套功法的区别   | 器匠、宗门门人             | 不把小说里用过的组合宣称为唯一正确玩法               |
| 旧物来历与交易风险                 | 亲历者、见过记录的商人     | 来源真实不等于收益保证；小说事件不能冒充玩家已经经历 |
| 正魔师承的生活与取舍               | 相应门人及有来往的散修     | 方法不同不等于道德阵营一致，也不能看穿高阶前辈       |
| 九幽残响与故人记忆的区别           | 确有见闻的修士             | 不因此获得通晓生死、召回父母的能力                   |
| 青岚后世如何记住离界者             | 明示出处的地方传闻         | 允许记载有限或失真，不把作者视角全部灌进每个人口中   |

陆迟的生平不宜原封不动成为所有NPC的共同记忆。若以后采用，只取适合其身份的一段见闻；涉及未开放秘境与终章的内容还要控制揭示时机。小说中的具体事故、器作、同行队伍与私人关系，不等于游戏已增加相应任务、组队或自由交易功能。

正文面向读者，说明面向作者。把有用知识取出来之后，仍应让玩家可以完全不读小说而正常游玩。
