## 难度模拟

`npm run balance` 使用固定随机种子及避敌、拾取、选技策略；模拟全程调用实际战斗引擎与游戏共用的 `src/autoplay.ts` 策略，不修改气血或伤害。

| 第一境难度 | 新存档三个固定种子的结果     |
| ---------- | ---------------------------- |
| 初入仙途   | 3 / 3 通关，约 316–327 秒    |
| 问道试炼   | 3 / 3 通关，约 313–356 秒    |
| 天劫降临   | 0 / 3 通关，约 94–154 秒失败 |

高难度面向已修炼根基、熟悉搭配的角色。结果是自动策略的回归样本，不是真人胜率，也不代表所有流派均已充分平衡。

连续六境模拟携带真实结算收益，局间自动修炼与炼器，六境均通关：316、391、442、487、571、620 秒。末境结算达到炼虚中期，仍可通过重复挑战向合体、大乘、渡劫成长。

## 当前边界

- 单人、本地进度，无账号、联网协作或云同步。
- 六境使用各自的循环地面纹理，环境中的石块与水面属于视觉装饰，不设碰撞障碍。
- AI 为本地走位与搭配策略，不保证通关；后台和暂停时停止，结算后不自动开下一局。
- 妖王共用三类招式逻辑，以立绘、气血、伤害与阶段速度区分。
- 完整数值平衡仍需要不同玩家与流派的持续体验；自动模拟用于排除明显断档和不可达关卡。
- localStorage 存档不能跨设备同步，异常中断最多回退约 5 秒。
