## 难度模拟

`npm run balance` 使用实际战斗引擎与游戏共用的 AI 策略，无气血或攻击作弊。以下是最终累加妖物池版本的固定种子样本。

| 第一境难度 | 新存档三个固定种子的结果                |
| ---------- | --------------------------------------- |
| 初入仙途   | 3 / 3 通关，310–326 秒                  |
| 问道试炼   | 3 / 3 通关，313–323 秒                  |
| 天劫降临   | 2 / 3 通关，329–332 秒；一组 139 秒失败 |

另外用 6 种新增本命法宝覆盖正道 3 组、魔道 3 组、兼修 6 组，初入仙途样本均通关；纯修只测试与流派兼容的本命。

连续六境模拟携带实际结算收益并在局间修炼炼器：前五境分别 308、389、436、497、565 秒通关。太虚天境前两次在 70、64 秒失败，第三次 612 秒通关。最终达到炼虚中期。

上述数据用于发现难度断档，并非真人胜率，也不代表所有组合均已平衡。新怪是累加到原有妖物池，原精英类型及其强度保留，后期额外加入高阶精英。

## 边界与运行注意

- 单人、本地进度，无账号或跨设备云同步。不同端口的 localStorage 相互隔离。
- 正道 / 魔道只限制新领悟；更新前的对局保留已有装备。
- 六位妖王有独立立绘，仍共用冲撞、环射与落地预警三类招式。
- AI 不保证通关，后台 / 暂停停止，结算后不自动开局。
- 本次曾因新图集未落盘就更新资源引用，触发游玩服务热更新后的素材加载失败。文件已补齐并确认可加载，随后移到独立工作树和端口开发；以后必须先确认资源到位再接入，不热更新正在游玩的实例。
