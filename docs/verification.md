### 连续升级卡死与正道气血修正

在正式旧版 5173 中注入正常三选一、LV 61、十万储备经验、手动模式的续局后，实际选择第一张卡。350 ms 后读到 `state=upgrade`、LV 62、仍有两条候选，但 DOM 中选择卡数量为 0、弹窗为空，稳定复现用户所述卡死。原因是 `choose` 将逻辑状态设回 playing 后未同步 `previousState`，下一帧直接再次进入 upgrade，界面误认为状态未变化；AI 仍可按约 0.9 秒节奏调用选项，所以停顿后自行恢复。

修正选择完成时的状态同步。Chrome DevTools MCP 复测相同快照：手动选择后 LV 62 / 63 均可见下一轮两张卡，选满后仅剩一个机缘自动领取，正常回到 playing；AI 模式连续采样 LV 61–64，所有 upgrade 状态都有可见选择卡，无隐藏暂停。修复已随 `index-CQc7Tv4c.js` 发布至正式 5173。

正道气血由固定 +12 改为总上限 ×1.12，计入基础、根基、境界与气血功法，四舍五入为整数。新增测试覆盖后期根基、功法领悟、当局突破和旧快照迁移；正道旧 542 / 575 气血续局在正式 5173 显示 598 / 631，保留已损失的 33 点，重复恢复不额外补血。路线说明实际显示「气血上限 +12%」。

正道持续回血由固定每秒 +0.2 改为「基础回血 + 功法回血」整体 ×1.2。测试覆盖功法 0 / 3 / 5 重，确认正道回复量比相同基础的魔道与兼修高 20%，并验证实际推进一帧后的气血变化。路线、指南与 README 同步说明；页面实际显示「持续回血速度 +20%」。

### 性能证据与限制

使用同一个第七关 607.9 秒快照（140 敌人、116 弹道、16 区域、121 掉落、六件法宝），对比发布前代码与优化代码。优化缓存按显示尺寸裁剪的角色图片和精英法阵，裁掉视野外区域，AI 最近掉落改为一次遍历，碰撞与寻敌比较使用距离平方。

- Node 固定种子片段每次推进 120 帧，预热后 35 次平均：24.86 ms → 16.64 ms，约减少 33%。两版结束时敌人数、弹道数、斩妖数、气血与角色坐标一致。
- Chrome 1440 × 900、DPR 2 的固定战场，缓存优化前后 rAF 中的绘制指令平均耗时约 1.18 ms → 0.81 ms，约减少 31%；帧间隔均约 8.3 ms，不能据此宣称实际帧率提高 31%。
- 升级界面等待两秒，旧版产生 32620 次 drawImage，冻结背景后为 0；进入选项仍绘制一次，返回战斗立即恢复。等待阶段未观察到超过 50 ms 的主线程长任务。
- 初次多测试页同时运行的采样受其他页面影响，已排除；强制像素读回测量会改变 Canvas 流水线，未作为用户帧率结论。没有取得真实低端设备或手机 GPU 的性能证据。

固定种子终关模拟（不使用广告复活）共 12 组，1 组在 628 秒自然通关，其余在 375–630 秒失败；所有样本未超过 100 级。Boss 奖励使成功斩王的低境界角色能更快突破，未通过终关仍卡在大乘后期。此为有限 AI 搭配样本，不代表真人胜率。
